> **AI is Good** — [HERE AND NOW AI](https://hereandnowai.com)

Course repository for the **Generative AI Professional Certification** program delivered by
HERE AND NOW AI in partnership with **EduHubSpot**, Season 2. It holds the hands-on

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or newer
- `git`
- An API key for your chosen LLM provider

### Setup

```bash
git clone https://github.com/hereandnowai/generative-ai-professional-certification-eduhubspot-s2.git
cd generative-ai-professional-certification-eduhubspot-s2

python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

### Environment Variables

Create a `.env` file in the project root (it is git-ignored):

```env
ANTHROPIC_API_KEY=your_api_key_here
```
